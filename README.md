# 🖥️ IT Support Home Lab

> 🚧 **Status:** Planned — this lab is being built out. Check back soon.

A virtualized home lab for hands-on IT support practice.

## Planned setup
- Hypervisor: Proxmox VE / VirtualBox
- Windows 10/11 and Ubuntu Linux virtual machines
- Active Directory domain with test users and Group Policy
- Ticketing workflow practice (incident lifecycle: intake → diagnosis → resolution → documentation)
- Snapshot-based break/fix exercises

## Goals
- Practice real-world troubleshooting in a safe environment
- Build Active Directory administration skills
- Document procedures like a production support team
